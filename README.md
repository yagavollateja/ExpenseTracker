# 💰 Expense Tracker

A full-stack **Expense Tracker Web Application** that helps users manage and monitor their daily expenses efficiently.  
This project allows users to add, view, and track expenses with a clean and interactive user interface.

---

## 🚀 Project Overview

Expense Tracker is a modern web application built with frontend and backend architecture.  
The goal of this project is to practice full-stack development, API integration, and real-world financial tracking features.

Users can:

- ➕ Add expenses
- 📊 Track spending
- 🧾 View expense history
- ⚡ Manage financial data easily

---

## 🛠️ Tech Stack

### 🌐 Frontend (Client)

### ⚙️ Backend (Server)

## ⚡ Installation & Setup

### 1️⃣ Clone the Repository

git clone https://github.com/yagavollateja/ExpenseTracker.git


### 2️⃣ Install Server Dependencies

cd server
npm install


### 3️⃣ Run Backend Server

npm start


### 4️⃣ Run Frontend

Open the **client** folder and run the project in browser or live server.
